# Checklist de Qualidade de Obra-Prima

## Frontend

- [ ] O frontend corresponde ao backend e vice-versa.
- [ ] O código está modularizado em componentes reutilizáveis.
- [ ] Testes de unidade e de integração cobrem a lógica principal.
- [ ] O tratamento de erros e exceções é robusto.
- [ ] Testes de segurança foram realizados para detectar vulnerabilidades (ex: XSS).
- [ ] A interface do usuário é intuitiva e segue os princípios de UX/UI definidos.
- [ ] A aplicação é responsiva e funciona bem em diferentes tamanhos de tela.

## Backend

- [ ] O backend está totalmente alinhado com os requisitos do projeto.
- [ ] O código está modularizado em serviços, controladores, etc.
- [ ] Testes de unidade e de integração cobrem todas as rotas e a lógica de negócios.
- [ ] O tratamento de erros é consistente em todas as rotas.
- [ ] Testes de segurança foram realizados para detectar vulnerabilidades (ex: SQL Injection, RCE).
- [ ] A API está bem documentada com exemplos de uso.
- [ ] A integração com serviços externos (OpenRouter) é resiliente e tem tratamento de falhas.

## Geral

- [ ] O código segue as convenções de estilo (ESLint, Prettier).
- [ ] As dependências estão atualizadas e não possuem vulnerabilidades conhecidas.
- [ ] O fluxo completo da aplicação (do upload à exportação) foi testado de ponta a ponta.
- [ ] A performance da aplicação foi avaliada e otimizada.
